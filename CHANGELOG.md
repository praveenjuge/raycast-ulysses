# Ulysses Changelog

## [Capture and Journal] - {PR_MERGE_DATE}

- New Quick Capture command: write a sheet with a title, text, group and format
- New Capture Text command: save typed text, the selected text, or the clipboard as a sheet
- New Journal Entry command: create a sheet titled with today's date in your Journal group, creating the group if needed
- New Group can now create a group inside a parent group, and requires a name
- Sheets sent to a group that doesn't exist now go to the Inbox instead of being lost
- Preferences for the default group, text format, and keeping Ulysses in the background
- Create a Quicklink that opens Quick Capture for a specific group
- Open All works again in current versions of Ulysses
- The "not installed" message now links to the Mac App Store and ulysses.app
- New icons for every command

## [Update to Raycast API 2] - {PR_MERGE_DATE}

- Updated to the latest Raycast API and tooling
- Group names with special characters like `&`, `#` or `?` now work in New Group

## [Initial Version] - 2022-01-21

- Initial release
